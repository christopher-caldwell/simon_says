# Isolated real-engine Fixer investigation

This user-requested exercise targets the `Count$LeftBattlefieldThisTurn Creature.YouCtrl` diagnostic observed in four retained Magic attempts. It clones the **recorded historical engine commit** into a new project, snapshots the actual Fixer profile, and starts the configured Fixer through Simon Says. It does not modify the original checkout, install a candidate runtime, run games, publish, or claim overall engine correctness. The candidate is a local checkpoint in the disposable clone. The frozen reviewer runs the focused Rust regression against the exact candidate in a fresh worktree.

The engine's recorded source includes an unused `forge` Git submodule. Simon Says v0 rejects submodules, so preparation removes only that gitlink in the new clone; it does not alter the source repo. A failed preparation can leave a new incomplete clone requiring inspection. The clone has full local Git history; the reference checkout can be dirty because the historical commit is read from Git objects, not its working tree. Keep isolated projects outside both sources.

```sh
python3 -B examples/magic-real-fix/prepare.py /absolute/manabrew /absolute/collection_plan /absolute/new/project
(cd /absolute/new/project && simon-says validate simon-workflow.toml)
DYLD_SHARED_REGION=avoid simon-says run /absolute/new/project/simon-workflow.toml --project /absolute/new/project --run-dir /absolute/new/run
simon-says status /absolute/new/run
```

Native provider authentication, Rust/Cargo dependencies and substantial time and space for isolated builds are required. The Fixer receives the existing source profile's configured model and effort. The task is bounded to source and tests under the engine crate, plus `repair.json`. The reviewer verifies the exact candidate and runs a nonempty integration-test target; it is a mechanical check, not independent judgment of all game rules.

## Independent review and corrected experiment

**The Fixer candidate `9e1307fd6ea721b9c7630e0bba7b62f742b1d005` is superseded and must not be treated as accepted.** After its initial tests passed, independent focused tests reproduced two defects: (1) a move replacement returned `Prevented` but the creature still moved and was counted as departed; (2) moving a creature from the battlefield directly to the bottom of a library bypassed its departure count. Both failures are retained in `../magic-prevented-test.log` and `../magic-bottom-before.log`. The first candidate separately passed 432 native library tests, 47 optimized integration tests and 250 archived rules checks, illustrating why those gates did not establish these missing edge cases.

The independently corrected experimental candidate is local commit `239a805ed23623f38f2cd8cfc1db969ba98598a5`, preserved as `experimental-corrected.patch`. It handles explicit `Prevented` move results and records creature departure in the existing bottom-of-library helper. Six focused tests passed, including prevention, redirect to exile, same-zone movement, controller versus owner, tokens, and noncreatures; ten neighboring zone tests also passed on the final run. An earlier run of that neighboring suite failed its random shuffle assertion when the unchanged library order happened to occur, then passed on rerun: this is an unresolved flaky-test concern. The helper still bypasses generic replacement/trigger machinery and has pre-existing token-lifecycle limitations. Other prevention callers, discard triggers, simultaneous departures and replacement/continuous-effect last-known information remain unverified. These patches are not installed or accepted runtimes.

`archived_expression.rs` is an additional focused test for the standalone copied native harness. It loads the actual card archive, obtains That's Rough Buddy's `Y` SVar and a real archived creature, checks one departure and verifies turn reset. It does not execute the complete card ability or a game, and it is independent of the native setup gate inventory. On the superseded v1 source it passed in `../magic-archived-check-v1`; a separate run on corrected source remains a distinct acceptance step.
